KPassword agora oferece instaladores Windows e Fedora a partir da mesma base de código.

- **Windows:** baixe `KPassword-Setup-v1.5.0.exe`. A chave de assinatura foi renovada porque a antiga foi perdida. Instale esta versão manualmente uma vez; as próximas atualizações poderão usar o atualizador novamente. Faça backup dos cofres antes de instalar. Não é necessário apagar dados nem cofres.
- **Fedora 44, x86_64:** baixe o `.rpm` e instale/atualize com `sudo dnf install ./KPassword-1.5.0-1.x86_64.rpm`. O botão de atualização abre a Release; a instalação é feita pelo DNF com autorização de administrador. Não há repositório DNF automático nesta versão.
- Cofres legados PBKDF2 e atuais Argon2id/AES-GCM continuam compatíveis. Os vetores independentes são verificados em Windows e Fedora.
- Fedora inclui clipboard, autostart, captura QR pelo portal do desktop, notificações e adaptação de renderização NVIDIA. Windows Hello permanece no Windows; Fedora utiliza senha mestra.
- A exclusão de cofre exige senha mestra e confirmação, preservando uma cópia criptografada para recuperação.
- Secrets Bridge é opcional e, nesta versão, o inicializador está disponível no Fedora. Cada abertura exige confirmação e verifica o executável previamente autorizado. `kpassword --bridge-request <chave-id> <integracao-id>` solicita uma nova abertura, sem retornar segredo ao solicitante.
- Claude Code e Codex CLI exigem cadastro explícito. DeepSeek requer cliente compatível configurado separadamente. Não há acesso automático para sites ou chats na nuvem.
- O programa autorizado recebe a chave selecionada e pode copiá-la. O Bridge não isola programas da mesma conta e bloquear o cofre não revoga a chave no provedor. Os testes utilizam dados fictícios; chamadas reais com todos os provedores não foram validadas.

Os arquivos `.sig` autenticam os instaladores com a chave pública da nova versão. `SHA256SUMS.txt` permite verificar downloads. A chave privada permanece criptografada no computador do mantenedor e não é enviada para GitHub, CI ou instaladores. A assinatura do RPM é externa (`.rpm.sig`), não uma assinatura GPG embutida para repositório DNF.

O teste visual foi feito no Fedora com KDE/Wayland e NVIDIA. O instalador Windows é compilado e testado em GitHub Actions; a interação visual Windows não foi testada num computador físico.
